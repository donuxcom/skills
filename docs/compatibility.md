# Compatibility

The skills use standard `SKILL.md` packages with `name`, `description`, `license`, `compatibility`, and string-valued metadata. They require a client able to read project files, write one HTML or Markdown text file, and ask for approval. They require no credentials, runtime package, or network access.

Agent Skills-compatible clients and manual project-local `.agents/skills/` installation are documented routes. The v0.1.0 baseline was validated structurally with local Python tooling; specific client and operating-system combinations remain untested. Client-specific install locations and tool names may differ. `allowed-tools` is intentionally omitted.
