## [0.1.0] - 2026-09-16

### Added
- Experimental codebase, domain, and product walkthrough skills.
- Responsive, printable standalone HTML output with subtle Donux styling by default.
- Optional Markdown output through `--format markdown`, `format: markdown`, or an explicit `.md` path.
- Shared HTML report shells included in each skill archive.
- Deterministic validation, security scanning, catalog, artifact, checksum, and test tooling.
- Governance, compatibility, architecture, security, and release documentation.

### Security
- Standalone HTML uses a restrictive Content Security Policy and requires repository-derived values to be escaped as plain text.
